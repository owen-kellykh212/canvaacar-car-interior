## Project Overview

Canvaacar is a static presentation site for automotive cabin services. It highlights seat refurbishment, headliner and roof lining projects, and other interior customization work, while giving visitors an overview of materials including leather and Alcantara. Completed projects are presented through visual examples.

The website is intended for vehicle owners looking to renew or personalize their interiors. French and English content, service information, before-and-after imagery, and direct contact options help visitors compare possibilities and submit a quote request.

## Included Capabilities

- Information about seat renovation and headliner services
- Showcase for automotive interior customization projects
- Gallery with before-and-after examples
- Material presentation for leather and Alcantara
- French and English user interface
- Project-specific internationalization built with HTML, CSS, and JavaScript
- Form for contact and quotation requests
- Direct WhatsApp and telephone contact methods

## Getting Started

Because Canvaacar is a static site, it does not need a server-side application or runtime.

```bash
git clone https://github.com/owen-kellykh212/canvaacar-car-interior.git
cd REPO
```

For a quick local check, open the primary HTML file in a browser. You can also launch a static server from the project directory:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` in your browser.

## Using the Site

1. Load the site in a current web browser.
2. Use the language controls to switch between French and English.
3. Explore the listed renovation and customization services.
4. View the material information and before-and-after examples.
5. Submit an inquiry through the contact or quote form.
6. Use WhatsApp or phone contact if that option is more convenient.

To publish the project, place its static files on a host capable of serving HTML, CSS, JavaScript, and media assets.

## Editing and Configuration

The language selector and translated interface strings are handled by the project's custom internationalization code. To revise existing wording or add supported language content, modify the appropriate translation data in JavaScript.

The related HTML and JavaScript files contain the service text, gallery items, material information, and contact details. Once edits are complete, reload the site in both languages to verify the translations and page layout.

## Common Questions

### Is Canvaacar available as a desktop program?

No. Canvaacar is a browser-based static website rather than a desktop application.

### What languages can users select?

The custom internationalization system provides French and English versions of the interface.

### How can someone ask for a quote?

Visitors may complete the contact or quote request form, or use one of the available WhatsApp and phone contact options.

### What content does the site present?

The website covers automotive interior services and materials, including leather and Alcantara, and also provides a before-and-after project gallery.

### How can I change the site information?

Update the applicable HTML sections and the translation data in the project files. Then run or open the site locally and refresh it to inspect the result.

### What can I do if the page is not displaying properly?

Check that the site is being opened from the intended project directory and that asset paths are correct. If local browser restrictions interfere with file loading, use a local static server. JavaScript and translation problems can be investigated through the browser console.

### What is the publishing process for changes?

Modify or build the static files, test the French and English versions, and upload the updated files to the configured static hosting location.
